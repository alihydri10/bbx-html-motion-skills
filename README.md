# BBX — HTML motion skills (Ali)

Claude skills for motion built with HTML and Three.js: scroll-driven 3D pages, WebGL scenes and code-built motion films.

Maintainer: Ali (alihydri10)

| Skill | What it does |
|---|---|
| `skills/threejs-scroll-cinema-site` | Build a scroll-driven 3D page (Three.js) from scratch with Blender models, then edit rounds (Tierris Section B workflow). |
| `skills/scroll-cinema` | Cinematic scroll-driven HTML story pages: Three.js scene or scrubbed footage, stage cards, data panels, no-WebGL fallback. |
| `skills/business-motion-film` | Premium short commercial for a real business with AI footage, HTML/GSAP motion, selective Three.js and a critic loop. |

Each skill is a folder with a `SKILL.md` plus helper files. To use one, zip its folder and upload it in Claude's Skills settings.

Other BBX skills (After Effects scripting, AI generation) live in [bbx-claude-skills](https://github.com/alihydri10/bbx-claude-skills).
